How it really runs

Play reports

When a play session ends, the game sends one small summary: how smoothly it ran, which graphics preset and graphics card it used, how long each area took and where the session ended. Nothing personal is in it: no names, no emails, no chat. Pick a release to see how it ran on everyone's PCs.

Reading the play reports…

This release has more reports than the page reads at once: the newest ones are shown.

By graphics preset

A frame is one picture. Fewer milliseconds is smoother: 16.7 ms is 60 frames a second, 33 ms is 30. The slow frames figure is what the slowest 1 in 100 frames cost in a typical session. The worst frame is the single slowest one in a typical session. A hitch is a frame over 50 ms, which you feel as a stutter.
