# Archive: obsolete and historical documents

Owner decision, 2026-10-09: Death Muffin is the Godot rebuild on `godot-next`; the web (three.js) game is frozen. Documents that only describe the web build's plans, work logs or tooling are marked **OBSOLETE** or **ARCHIVED** with a banner at the top of the file. Current status lives in [ROADMAP.md](../ROADMAP.md), [godot/REBUILD.md](../godot/REBUILD.md) and [godot/PARITY.md](../godot/PARITY.md).

## Why the files were marked, not moved

Moved files break every link to them, and many are linked from other documents, source comments, scripts and agent skills. Every archived file therefore keeps its path; the banner and this index are the archive. If you later want a physical move, do it in one change with `git mv` and fix the links listed in the last column.

## Still current, do not archive

- `server/` docs and `docs/DEATH-MUFFIN-HANDOFF.md`, `docs/SERVER-AUTHORITY.md`, `SERVER_OPERATIONS.md`: the backend is live and shared by the Godot client.
- `CLAUDE.md`, `ASSET_PIPELINE.md`, `BALANCE.md`, `docs/GRIND-LOOP.md`, `FUTURE_CONTENT.md`: referenced by the agent instructions and by server proposals; still the source for content, tuning and art rules.
- `docs/PERF-BUDGET.md`, `docs/BLENDER-AUDIT.md`, `docs/ZONE-POLISH-AUDIT.md`: referenced by the skills under `.claude/` (which agents may not edit), so they must keep their paths.

- `docs/AUDIO-SOURCES.md`, `docs/LEGENDARY-SETS.md`, `docs/ARMOR-SETS.md`, `docs/NECRO-WEAPONS.md`, `docs/BLENDER-PIPELINE.md`: rules, data and licence records still used by the rebuild's content.
