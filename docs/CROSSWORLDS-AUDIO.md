# Crossworlds audio accents

Three short source recordings were extracted from the local
`/home/ubuntu/Crossworlds-WindowsClient-20260822.zip` Unity client archive,
`Crossworlds_Data/sharedassets0.assets` / `sharedassets0.resource`. They were
converted to mono 32 kHz Ogg Vorbis (quality 3) for Death Muffin. The original
procedural spell sounds remain audible if these optional files are unavailable.

| Game file | Unity AudioClip | Use |
| --- | --- | --- |
| `dark-magic-spell-1.ogg` | `Dark Magic Spell 1` | Litany layer |
| `dark-magic-spell-2.ogg` | `Dark Magic Spell 2` | Exhume layer |
| `magic-cast-whoosh-2-1.ogg` | `Magic Cast Whoosh 2-1` | Veil rite layer |

The archive did not contain a separate audio license or attribution file. Confirm
the source recordings' redistribution rights before including them in a public
release. The game changes here are staged only, with no deployment.
