# docs/

What is left here is the shared asset pipeline and the licence and source records. Game documentation is in the repository root
(`README.md`, `ROADMAP.md`, `DECISIONS.md`, `KNOWN-GAPS.md`, `CLAUDE.md`), `godot/` and `server/`.

| File | What it is |
|---|---|
| [AUDIO-SOURCES.md](AUDIO-SOURCES.md) | Every shipped audio file with its origin and licence (Epic Stock Media pack, Kenney CC0, generated, ElevenLabs). Read before adding audio |
| [audio/esm-fantasy-game-files.txt](audio/esm-fantasy-game-files.txt) | File list of the licensed pack (clip names in the audio map refer to it) |
| [audio/ELEVEN-MUSIC-DRAFTS.md](audio/ELEVEN-MUSIC-DRAFTS.md) | Music drafts and the ElevenLabs rights note |
| [ANIMATION-SOURCES.md](ANIMATION-SOURCES.md) | Origin and licence of every animation that did not come from Tripo's presets |
| [licenses/](licenses/) | Licence texts (Quaternius Universal Animation Library, CC0) |
| [BLENDER-PIPELINE.md](BLENDER-PIPELINE.md) | Headless Blender animation tools (`tools/blender.mjs`): procedural gaits, rig fixes, cleanup, CC0 retargeting |
| [TRIPO-ANIMATE-IN-PLACE.md](TRIPO-ANIMATE-IN-PLACE.md) | Verdict: `animate_in_place` and GLB retargets on Tripo v1.0 rigs are fine; validator tools |
| [GRAVECRAWL.md](GRAVECRAWL.md) | The quality bar: what Gravecrawl does better and what to take from it |
| [art/areas/](art/areas/) | Area moodboards generated by the art manifest (level-design reference, not in-game textures) |

Asset generation (Gemini concept to Tripo model) is in `ASSET_PIPELINE.md` at the repository root; this folder only holds the Blender animation tools and the records.
